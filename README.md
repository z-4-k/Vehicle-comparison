# Vehicle Benchmarks static site

Files:
- index.html — interactive table application; normally does not need to change.
- data.js — table data. Update this file to refresh the live table at the same URL.

Recommended hosting: GitHub Pages from a public repository.
1. Create a public repository.
2. Upload index.html and data.js to the repository root.
3. Settings → Pages → Deploy from a branch → main / root.
4. Share the resulting https://<username>.github.io/<repo>/ URL.

Future updates: replace data.js in the same repository. The public URL stays unchanged.
