Credits

Project concept, product direction and domain requirements: Zoli.

Data-model design, frontend implementation, research workflow and technical assistance: developed collaboratively with ChatGPT by OpenAI.

Technology

Application: standards-based HTML, CSS and JavaScript with no required frontend framework.

Database: Supabase / PostgreSQL with PostgREST, row-level security and audit history.

Hosting and source control: GitHub and GitHub Pages.

Research and conversion tooling: web research, source comparison, unit conversion and time-stamped currency-rate data are used when records are populated or normalized.

Repository

Project: z-4-k/Vehicle-comparison

Public deployment: GitHub Pages. The browser interface is read-only; database writes are handled separately under controlled authorization.

Contributions

Corrections and new records should include the original source, source date or observation date, market/region, source-native units and currency where applicable.

Conflicting credible sources should be preserved as separate observations rather than silently overwriting one another. Canonical values and derived conversions should remain traceable back to their source observations.

Performance claims should identify whether they are manufacturer claims, independent measurements, instrumented tests or derived values whenever that information is available.

Data-source policy

Preference is given to manufacturer documentation, homologation/official technical material and reputable instrumented testing. Secondary sources may be retained with appropriate provenance and validation status.
